05 FIG. 3 — APPLY CHAIN

The one thing that needs a process

The agent is a local service on port 3457. It drives Chromium, matches fields to your record, attaches the PDF, and stops.

! It does not submit unless submit and confirmSubmit are both true. Two clicks, both yours.

$ npm run jobs:api

  1. INPUTPosting URL pasted from Greenhouse, Lever, Ashby or Workable.
  2. MATCHForm fields mapped to the stored record; unmatched fields flagged.
  3. ATTACHCurrent PDF export attached from disk. Nothing re-uploaded.
  4. HOLDFilled form left open. Submit waits for both confirmations.
