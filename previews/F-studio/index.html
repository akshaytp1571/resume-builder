02

Where résumés actually die

Six ways in.
All six named.

Most rejections happen before a person reads a word. These are the six the scorer looks for, and each one has a fix the editor will do for you.

  1. 01

    Two-column body

    A side table reads as interleaved lines. Text order inverts and the summary lands after the phone number.

    Fix · collapse to one column
  2. 02

    Contact inside a header

    Anything grouped in a graphic header is skipped whole. The parser reports a résumé with no way to reply.

    Fix · lift to a plain text block
  3. 03

    En-dash date ranges

    “2021 — Present” is read as a role some of the time. The date column returns empty and the tenure scores zero.

    Fix · normalise to a hyphen
  4. 04

    Skills as a graphic

    Dots and bars have no text. A five-dot rating extracts as nothing at all, and the skill is simply lost.

    Fix · print the level as a word
  5. 05

    Spill past one page

    A line crossing the page edge is cut, not wrapped. The last bullet of the last role is the one that goes.

    Fix · show the spill before export
  6. 06

    Decorative glyph bullets

    A dingbat before every line attaches to the previous line on extraction, doubling the length of the parse.

    Fix · plain hyphens, always
